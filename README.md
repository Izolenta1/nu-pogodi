# Ну, погоди!

Браузерная версия карманной электронной игры «Ну, погоди!» (ИМ-02, 1984). Волк ловит яйца, скатывающиеся из четырёх гнёзд. Проект не повторяет геймплей оригинала один в один.

## Запуск

Нужны [Node.js](https://nodejs.org/) и npm. Команды выполняются из каталога приложения:

```bash
cd nu-pogodi
npm install
npm run start
```

`npm run start` собирает проект и поднимает превью на [http://localhost:5173](http://localhost:5173).

Для разработки с горячей перезагрузкой:

```bash
npm run dev
```

Сервер разработки слушает тот же адрес.

## Управление

| Клавиши | Действие |
| --- | --- |
| `Q` `E` | Верхние гнёзда |
| `A` `D` | Нижние гнёзда |
| `1` `2` `3` | Режимы приставки |

Пойманное яйцо даёт 1 очко, а пока на экране заяц — 2. Партия кончается на четвёртом промахе. 1000 очков — победа.
